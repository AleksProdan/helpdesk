# HelpDesk

Internes Ticketsystem für die zentrale Verwaltung von IT-Support-Anfragen.

## Ziel

Mitarbeiter außerhalb der IT können IT-Probleme und Anfragen als Tickets erfassen.
Supportmitarbeiter können diese Tickets zentral verwalten, übernehmen und bearbeiten.

## Tech Stack

- React
- TypeScript
- Vite
- Node.js
- NestJS
- PostgreSQL
- Prisma
- Docker
